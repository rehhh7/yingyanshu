# 四级单词卡 · 需求与迭代说明

## 一、项目定位
apk格式
当前版本：v2（605 词 + 单词表模式）

## 二、核心需求（用户原始要求）
1. 卡片正面：四级单词 + 音标 + 发音按钮（🔊）
2. 卡片背面：中文释义 + 近义词组（意思相近但【用法不同】的单词，讲清用法区别——不是标"哪里不能用"）+ 形近词组
3. 近义词、形近词可以选自六级或雅思，每个后面也要发音按钮
4. 可翻页复习；可自己添加新单词（分组）
5. 单词表模式：中英对照 / 纯英文两种显示，按 Day 分组
   - 用途：快速扫一遍找出不会的单词
   - 单词表中标 ⭐ 的词进"生词组"
6. 生词组 = 主动标记的词；卡片模式筛"生词"集中背；✓认识自动移出生词组；✗不认识也会进生词组
