# 英眼书 · 各大应用商店上架操作手册

> 前提说明：上架过程中所有需要**实名认证、身份证、人脸、支付**的环节只能你本人完成，我无法代办；本手册把每一步列清楚，材料类的东西（隐私政策、文案、权限说明）已备好，见同目录文件。

---

## 第 0 步：先解决三个 App 本身的问题（不改必被拒）

1. **当前 APK 是 Debug 包**：`AndroidManifest` 里 `debuggable=true`，所有商店一律拒收。需要在 Godot 导出时用 **Release 模板 + 正式 keystore 签名**重新出包。keystore 文件和密码务必永久保存（丢了就无法覆盖更新）。
2. **`isGame=true` 被标成了"游戏"**：背单词应用应归教育类，否则会被要求提供游戏版号（个人基本办不下来）。在 Godot 导出预设的 Android Manifest 附加内容里去掉/覆盖 isGame。
3. **包名 `com.kimi.cet4words` 含 "kimi"**：与月之暗面 Kimi 同名，审核时可能被质疑商标归属。**包名一旦上架不能改**（改了等于新应用，老用户收不到更新），建议趁还没上架改成如 `com.yanyanshu.app` 之类；改名后老 APK 用户数据会丢，但现在用户量小，越早改代价越小。

## 第 1 步：APP 备案（约 2–4 周，周期最长，最先办）

工信部要求：境内提供互联网信息服务的 App **先备案后上架**，备案号格式如 `京ICP备XXXXXXXX号-1A`。

1. 需要一个**已 ICP 备案的域名**（没有的话先买域名 + 在阿里云/腾讯云做网站 ICP 备案，个人可办，约 1–2 周）。
2. 在**云服务商备案系统**（阿里云/腾讯云/华为云的"APP 备案"入口）提交：填应用名「英眼书」、包名、平台（Android）、签名证书指纹（MD5/SHA1，可从 keystore 提取）等信息，按要求用 App 扫脸核验。
3. 管局审核通过后获得备案号，**需要把备案号展示在应用内**（建议加在设置-关于页）。
4. 注意：APP 备案和网站 ICP 备案是两个号；纯单机不联网 App 个别商店可豁免，但本应用有 AI 联网功能，必须备。

## 第 2 步：软件著作权（约 30–60 个工作日，可与备案并行）

1. 登录**中国版权保护中心**（ccopyright.com.cn）在线申请，个人即可，费用低（自行办理约几十元官费）。
2. 关键硬规则：**软著登记名称必须与上架应用名称一字不差** → 登记名就叫「英眼书」。
3. 著作权人必须与你注册商店开发者账号的主体一致（都是同一个人）。
4. 材料：源代码前后各 30 页、操作说明书（可截取 App 界面图 + 功能说明，工程里有现成截图）。
5. 嫌慢可找代理加急（约 7 个工作日，费用数百元）。

## 第 3 步：隐私政策网页

1. 用本目录的 `隐私政策.html`，部署到你的**已备案域名**下，如 `https://你的域名.com/privacy.html`，确保无登录、无拦截、手机可访问。
2. 取得备案号后，把备案号填进 HTML 第九节和 App 内"关于"页。
3. **App 首次启动必须弹隐私政策同意框**（不同意则退出）——商店合规检测必查项。当前版本如无此弹窗，需要加一个小版本（v0.9.8）补上。
4. 商店后台"隐私政策 URL"统一填上面的链接。

## 第 4 步：注册各商店开发者账号并提审

个人开发者可注册的渠道（2026 年情况，以各平台最新公告为准）：

| 商店 | 开发者类型 | 认证费 | 审核周期 | 特别要求 |
|---|---|---|---|---|
| 华为 AppGallery | 个人/企业 | 免费（个人实名） | 3–5 个工作日 | 软著、APP 备案号、targetSdk≥30（本应用 36 没问题） |
| 小米 | 个人/企业 | 免费 | 2–4 个工作日 | 软著、备案号；截图不能带其他品牌手机水印 |
| OPPO | 个人/企业 | 约 300 元 | 3–5 个工作日 | 软著、备案号；企业需对公账户 |
| vivo | **仅企业** | 约 300 元 | 3–7 个工作日 | 软著名称必须与 App 名一致 |
| 腾讯应用宝 | 个人/企业 | 免费 | 5–7 个工作日 | 可用电子版权认证替代软著；对质量要求最高 |
| 荣耀 | 个人/企业 | 免费 | 3–5 个工作日 | 材料同华为 |
| 360 / 百度 | 个人/企业 | 免费 | 2–5 个工作日 | 部分要求安全检测报告 |

每个商店提交流程大同小异：实名认证 → 创建应用（名称「英眼书」、包名、分类选教育）→ 上传 Release 签名 APK → 填商店文案（用 `商店文案.md`）→ 填备案号、软著号、隐私政策 URL → 提交审核。

## 第 5 步：时间线建议

```
本周      ① 改包名/isGame、加隐私弹窗+备案号展示 → 出 v0.9.8 Release 正式签名包
          ② 买域名 + 网站 ICP 备案；部署隐私政策页
          ③ 同时提交软著申请 + APP 备案
第 2–6 周  等备案号、等软著（互不阻塞）
拿到双证    注册华为/小米/应用宝/荣耀等开发者账号，逐一提审
```

## 高频驳回原因自查表

- [ ] APK 是 Debug 包 / debuggable=true
- [ ] 软著名称与 App 名不一致 / 主体不一致
- [ ] 无 APP 备案号或备案主体与开发者不一致
- [ ] 隐私政策链接打不开 / 与 App 实际行为不符
- [ ] 首次启动无隐私政策弹窗
- [ ] isGame=true 被当游戏要版号
- [ ] 权限与实际功能不符（本应用仅 INTERNET，文案要解释清楚 AI 功能）
- [ ] 应用内出现第三方 AI 服务名称的商标问题（描述中提及 DeepSeek/Moonshot 作为"用户自配置服务"通常可以，避免暗示官方合作）
