## 一句话简介（80 字内）

拟物化卡片背单词：四级单词+听力词组分区学习，星标生词、TTS 朗读、听写统计，词库可自己编辑导入，还支持接入 AI 助手帮你整理词库、出听写题。

## 详细描述

英眼书是一款干净、离线可用的四级英语背单词应用，没有广告、没有账号、没有打扰。

【卡片式学习】
单词与听力词组两个独立列表，按 Day / Part 分组，点卡片翻面看释义，系统 TTS 朗读支持 0.7 倍慢速。点击星号收藏生词，底部「生词」页集中复习。

【听写与统计】
内置听写出题，自动批改；统计页记录连续打卡天数、今日学习量、已会/生词比例、听写正确率。

【自己的词库】
词库是开放的 Markdown 文件：支持导入 txt/md/docx 文本自动识别词条、逐条确认入库；也可以在应用内直接添加、编辑词条；每次改动自动备份，可一键回滚，可导出 Word/JSON 备份。

【AI 助手（可选）】
设置里填入你自己的 DeepSeek / Moonshot 等 API 密钥后，可以让 AI 帮你配近义词、整理导入的词表、出听写题、分析学习数据。词库修改一律经过你的逐条确认才会写入，且写入前自动备份、随时可回滚。不用 AI 时应用完全离线运行。

【顺手的细节】
米白拟物风 + 深色模式；手机平板横竖屏自适应；字体、按钮大小可调；自定义壁纸；自定义分组名；全局手势滑动带惯性。

隐私承诺：不注册账号、不收集个人信息、不集成广告与统计 SDK，全部数据只存在你的手机里。
